# homebrew-tap

Homebrew tap for my personal macOS tools and forks.

## Install

```bash
brew install dingtang2008/tap/<formula>
```

## Available formulas

| Formula | Description |
|---|---|
| [`go2shell`](Casks/go2shell.rb) | Open terminal from Finder toolbar — [fork](https://github.com/dingtang2008/go2shell) with FinderSync extensions, HIG-compliant icon, network-drive support |
| [`zhibi`](Casks/zhibi.rb) | 执笔 — AI reply pane for the new Outlook for Mac ([source](https://github.com/ElvisLabs/zhibi)); `brew install --cask elvislabs/tap/zhibi` |

## Uninstall a formula

```bash
brew uninstall --cask <formula>
```

## Remove the tap

```bash
brew untap dingtang2008/tap
```
